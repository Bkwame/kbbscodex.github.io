## A small example

Given a read of length $\ell$ and a $k$-mer size of $k$, the number of $k$-mers per read is

$$
n_k = \ell - k + 1.
$$

For Illumina-style 150 bp reads with $k = 21$, that's 130 minimizers per read before any
sketching. Useful to keep in your head when you're sizing a hash table.

```python
def kmers(seq: str, k: int):
    """Yield all k-mers of length k from seq."""
    for i in range(len(seq) - k + 1):
        yield seq[i : i + k]

list(kmers("ACGTACGT", 3))
# ['ACG', 'CGT', 'GTA', 'TAC', 'ACG', 'CGT']
```
