[minimap2](https://github.com/lh3/minimap2) is the de-facto aligner for long reads.
Here's the minimum I needed to get from a FASTQ to a sorted BAM.

## The pipeline

```bash
# Index once (optional but speeds up repeated runs)
minimap2 -d ref.mmi reference.fa

# Align Nanopore reads, pipe straight into samtools
minimap2 -ax map-ont -t 8 ref.mmi reads.fq.gz \
  | samtools sort -@ 4 -o aligned.bam -
samtools index aligned.bam
```

Three flags doing the heavy lifting:

| Flag       | Meaning                                                         |
| ---------- | --------------------------------------------------------------- |
| `-a`       | Output SAM (so we can pipe to samtools)                         |
| `-x map-ont` | Preset for noisy long reads (PacBio HiFi: `map-hifi`)         |
| `-t 8`     | Use 8 threads                                                   |

## Sanity-checking the output

```bash
samtools flagstat aligned.bam
```

I look for two numbers:

1. **mapped %** — should be > 90 % for a well-matched reference.
2. **supplementary %** — high values suggest structural variation or chimeric reads.

## Common mistakes I've already made

- Forgetting `-x map-ont` and getting wildly wrong alignments because the default preset
  assumes short, accurate reads.
- Skipping `samtools sort` and then wondering why downstream tools complain.
- Indexing the reference with the wrong `-k` / `-w` and silently using a stale `.mmi`.
